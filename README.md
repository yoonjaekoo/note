# Note

Windows용 미니멀 수학 필기 도구. 외부 라이브러리/빌드 없이 정적 HTML/CSS/JS로 동작한다.

## 구성
- `index.html` — 앱 UI
- `app.css` — 디자인 시스템/스타일
- `app.js` — 캔버스 필기, 수학 입력, 저장/열기
- `DESIGN.md` — 디자인 시스템 문서
- `Start-Note.cmd` — Windows 실행(Edge 앱 모드 우선, 없으면 기본 브라우저)

## Windows 실행
1. `Start-Note.cmd` 더블클릭.
2. 또는 `index.html`을 브라우저에서 직접 열기.

Edge가 설치되어 있으면 앱 모드 창으로 실행된다. Windows 10/11 기본 환경 기준.

## 기능
- **필기/도형**: 펜/지우개/직선/사각형/원·타원/다각형/텍스트 (Pointer Events). 직선 Shift=각도 스냅, 사각형 Shift=정사각형, 원·타원 도구는 기본 타원이며 **Shift=정원만**. 다각형은 클릭으로 꼭짓점 추가, 시작점 클릭/더블클릭/Enter로 완성, Esc 취소.
- **곡선 인식(그래프)**: `C`로 토글. 펜으로 그린 선을 단순화(RDP) 후 부드러운 곡선으로 정리해 그래프/곡선 스케치에 사용.
- **보기/확대**: `Ctrl`+휠 확대/축소(25%–400%), `Ctrl+=`/`Ctrl+-`/`Ctrl+0`, 이동 `H`·`Space` 드래그 패닝, 격자 `G`.
- **수학 도구** (`M`): 기호/템플릿 팔레트, 수식·텍스트 배치, 로컬 계산기(`sqrt/sin/cos/tan/log/abs/pi`, `^`) 및 `식 = 결과` 배치.
- **편집/파일**: 제한된 잉크(검정/회색/강조), 굵기, 실행 취소/다시 실행, 페이지 지우기, `.notemath.json` 저장/열기.
- 단축키: `P/E/L/R/O/Y/T/H/M/C/G`, `Ctrl+Z/Y/S`, `Ctrl+=/-/0`.

## 제약/방향
- 필기 영역 중심, 장식 요소 최소화.
- 네온/그라데이션/글로우/유리 효과/과도한 애니메이션 없음.
- 의존성 0, 초기 로딩 최소화, 저사양 환경 고려.
- 현재 범위: Windows 단일 페이지 필기 프로토타입. 다중 페이지, 필압 고급 처리, PDF 주석, 클라우드 동기화는 미포함.
